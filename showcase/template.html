Shared Memory Lab

Agents that match ontologies, reason over them, and attack them never call each other. They share one pool of memory. Load an ontology, ask MOIRA about it, then change it as a curator or attack it, and watch Aegis and Mneme respond.

Attacks on the memory itself

Attacks on the agents' shared memory itself, from the honest state after step 3. Each is run twice: with no defences, and with Aegis's memory defences on: a writer policy learned from the honest run, required provenance for matches and answers, a sealed log, a laundering check, and a probe monitor that repairs by attribution.

The system. Agents: KROMA matches ontologies; MOIRA does relational reasoning, choosing from a list of tools as it goes (retrieval is one of them: search_term_context, search_knowledge_graph, search_nodes); Aegis attacks as a white hat and defends; Hermes generates queries (planned). Memory: Mneme, one pool all agents share. Ontologies: OntoDB.
Reproduce: uv run python showcase/record.py then python showcase/build.py in the moira repository, with the other projects cloned beside it.
